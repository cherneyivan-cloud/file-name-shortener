# Частые вопросы и ошибки

## `[WinError 5] Отказано в доступе` при переименовании

**Причина:** файл открыт в другой программе (проводник, AutoCAD, Word) или недостаточно прав.

**Решение:**
1. Закройте все программы, которые могут держать файл.
2. Убедитесь, что у вас есть права на запись в целевую папку.
3. Повторный запуск — скрипт делает 3 попытки, но ручное вмешательство может потребоваться.

## `PermissionError: [Errno 13] Permission denied: 'rename_log.txt'`

**Причина:** лог-файл открыт в Блокноте/Excel.

**Решение:** закройте его. Скрипт сам сохранит лог в резервный файл (`rename_log_1.txt`, `%TEMP%\rename_log.txt` и т.п.) и продолжит работу.

## Файлы с очень длинными именами пропускаются

**Причина:** путь превышает 260 символов, и стандартные функции Python не справляются.

**Решение:** используйте последнюю версию скрипта — она обходит пути с префиксом `\\?\` и использует `MoveFileW`. Убедитесь, что скрипт запущен на Windows.

## Программа закрывается сразу после запуска

**Причина:** запуск двойным кликом по `.py` без консоли.

**Решение:** запускайте из `cmd` / PowerShell:
```cmd
python shorten_filenames.py
```

## Как добавить своё сокращение?

Запустите:
```bash
python shorten_filenames.py --add
```
или добавьте вручную в `custom_rules.json`:
```json
[{ "original": "Моё слово", "replacement": "МС" }]
```

## Как откатить переименование?

Скрипт **не делает резервных копий**. Перед первым запуском сделайте копию папки или используйте режим `--dry-run` для проверки. Восстановить имена можно вручную по `rename_log.txt`.
