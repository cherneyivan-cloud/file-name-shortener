# Подробное руководство

## Запуск без параметров

```bash
python shorten_filenames.py
```

Появится меню с четырьмя режимами (см. README).

## Параметры командной строки

| Ключ | Описание |
|------|----------|
| `--add` / `-add` | Добавить новые сокращения в `custom_rules.json` и выйти. |
| `--dry-run` / `-n` | Предпросмотр: показать изменения, **не переименовывая**. |
| `--apply` / `-a` | Автоматический режим: применить изменения без подтверждения. |
| `<путь>` | Корневая папка для обработки. Если не указана — спросит интерактивно. |

### Примеры

```bash
# Предпросмотр
python shorten_filenames.py "D:\Проекты\Каширское ш." --dry-run

# Применить без вопросов
python shorten_filenames.py "D:\Проекты\Каширское ш." --apply

# Сетевая папка
python shorten_filenames.py "\\server\share\Проект" --dry-run

# Добавить правило
python shorten_filenames.py --add
```

## Как программа обрабатывает имена

1. Применяются **пользовательские правила** (из `custom_rules.json`).
2. Применяются **встроенные правила** (регулярные выражения).
3. Все `.` в имени (кроме последней у файлов) → `_`.
4. Все пробелы → `_`.
5. Множественные `_` и `-` схлопываются.
6. Итоговое имя **усекается до 80 символов** (расширение сохраняется).

## Порядок переименования

Элементы переименовываются **от самых глубоких к корневым**, чтобы изменение имени родительской папки не ломало пути дочерних.

## Разрешение конфликтов

Если два разных элемента после сокращения дают одинаковое имя, к ним добавляется суффикс `_2`, `_3`, ...
