# Встроенные правила сокращения

Все правила применяются **без учёта регистра**.

| Исходное выражение | Замена | Пример |
|-------------------|--------|--------|
| `Строительство` | `стр-во` | `Строительство дороги` → `стр-во_дороги` |
| `Строительства` | `стр-ва` | `Проект строительства` → `Проект_стр-ва` |
| `Переустройство` | `пер-во` | `Переустройство сетей` → `пер-во_сетей` |
| `назначения` | `назн` | `Ведомость назначения` → `В_назн` |
| `Оформление` / `оформление` | `оф` | `Оформление чертежей` → `оф_чертежей` |
| `Общие данные` | `ОД` | `Общие данные.pdf` → `ОД.pdf` |
| `асфальтобетон` | `аб` | `асфальтобетон смесь` → `аб_смесь` |
| `Ведомость` / `Ведомости` | `В` | `Ведомость объёмов` → `В_объёмов` |
| `Дорожной` | `дор` | `Дорожной покрытие` → `дор_покрытие` |
| `Конструктивных` | `кон` | `Конструктивных решений` → `кон_решений` |
| `Раздел №N` | `РN` | `Раздел №5` → `Р5` |
| `Подраздел №N` | `ПN` | `Подраздел №3` → `П3` |
| `Часть №N` | `ЧN` | `Часть №1` → `Ч1` |
| `Книга №N` | `КN` | `Книга №3` → `К3` |
| `(изм.N)` / `Изм.N` | `ИN` | `(изм.1)` → `И1` |
| `Внешние_ссылки` | `ВС` | `Внешние_ссылки.dwg` → `ВС.dwg` |
| `Базовый_комплект` | `БК` | `Базовый_комплект.pdf` → `БК.pdf` |
| `Электроснабжение` | `ЭН` | `Электроснабжение здания` → `ЭН_здания` |
| `Сводный план` / `Сводный_план` | `СП` | `Сводный план` → `СП` |
| `Конструкция_дор_одежды` | `КДО` | — |
| `Разбивочный_чертёж` | `РЧ` | — |
| `Временная_металлическая_труба` | `ВМТ` | — |
| `Планировки` | `П` | — |
| `Укрепления` | `Ук` | — |
| `Территории` | `тер` | — |
| `покр` | `п` | — |
| `Съезд` | `с` | — |
| `Попикетная` | `П` | — |
| `Ведомость_верха_кон_слоев_дор_одежды` | `Вв_КДО` | — |
| `Верхний_слой` | `вс` | — |
| `Верхний_слой_основания` | `всс` | — |
| `Нижний_слой_основания_слой` | `нсос` | — |
| `Картограммы_планировки_территорий` | `карт_план_тер` | — |

> Пробелы (`\s+`) заменяются на `_`, знак `№` — на `#`, все недопустимые символы удаляются.
