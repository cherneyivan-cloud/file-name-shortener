# Как внести вклад в проект

Спасибо за интерес! Ниже — короткое руководство.

## Сообщения об ошибках

Создайте [issue](https://github.com/cherneyivan-cloud/file-name-shortener/issues) и приложите:

1. Версию Python и ОС (`python --version`, `winver`).
2. Текст ошибки из консоли **и** последние строки `rename_log.txt`.
3. Минимальный пример пути, на котором воспроизводится проблема
   (можно замаскировать конфиденциальные части).

## Pull request

1. Форкните репозиторий и создайте ветку:
   ```bash
   git checkout -b feature/название-фичи
   ```
2. Внесите изменения, придерживаясь стиля существующего кода (PEP 8).
3. Обновите `CHANGELOG.md` в разделе `[Unreleased]`.
4. Убедитесь, что скрипт запускается без ошибок на тестовой папке.
5. Создайте PR с описанием изменений и ссылкой на issue.

## Добавление новых правил сокращений

- Встроенные правила живут в словаре `BUILTIN_REPLACEMENTS` (в `shorten_filenames.py`).
- **Пользовательские** правила не нужно добавлять в код — предложите пользователю режим `--add`.
- Если правило типовое (общеупотребительное) — создайте PR с добавлением в `BUILTIN_REPLACEMENTS`
  и обязательно обновите `docs/RULES.md`.

## Стиль кода

- Python 3.8+, PEP 8.
- Функции — с docstring.
- Комментарии — на русском или английском (единообразно в пределах файла).

## Лицензия

Отправляя PR, вы соглашаетесь, что ваш вклад распространяется под лицензией **MIT**.
