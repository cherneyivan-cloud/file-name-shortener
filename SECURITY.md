# Безопасность

## Поддерживаемые версии

Обновления безопасности выпускаются только для актуальной стабильной версии.
Старые версии исправления не получают — используйте последний релиз.

| Версия | Поддержка |
|--------|-----------|
| 1.x (последний релиз) | ✅ получает исправления |
| Более старые | ❌ не поддерживаются |

## Как сообщить об уязвимости

Скрипт работает локально и не отправляет данные в сеть, поэтому поверхность
атаки ограничена. Тем не менее:

1. **Не создавайте публичный issue** для уязвимостей безопасности.
2. Напишите на приватный канал: создайте issue с пометкой `[SECURITY]`
   (доступно только владельцу репозитория) или отправьте письмо
   владельцу репозитория через GitHub.
3. Опишите: версию Python и ОС, шаги воспроизведения, минимальный пример
   имени файла/папки, на котором срабатывает проблема, ожидаемое и
   фактическое поведение.
4. Не публикуйте детали до исправления или ответа (в среднем — 7 дней).

## Основные риски при использовании

- Переименование выполняется **безвозвратно** (без резервных копий) —
  всегда проверяйте результат в режиме `--dry-run` и держите резервную копию.
- Пользовательские правила загружаются из `custom_rules.json` — не берите
  чужие файлы правил без проверки: результат подставляется в имена файлов.
- Скрипт не выполняет произвольный код и не обращается к сети.
