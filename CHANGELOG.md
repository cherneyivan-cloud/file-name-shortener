## [Unreleased]

### Добавлено
- Реальный режим предпросмотра `--dry-run`: показывает список изменений и **не применяет** их.
- Резервное сохранение лога при блокировке `rename_log.txt` (`rename_log_1.txt`, ..., `%TEMP%\rename_log.txt`) — программа не падает.
- CI-проверка синтаксиса через GitHub Actions (`.github/workflows/lint.yml`).
- `SECURITY.md` с правилами сообщения об уязвимостях.

### Изменено
- В режиме предпросмотра предупреждение о длинных путях больше не запрашивает подтверждение.

## [1.0.0] — 2026-10-19

### Добавлено
- Первый публичный релиз.
- Четыре режима работы (добавление правил, предпросмотр, интерактивный, автоматический).
- Встроенный словарь сокращений (разделы, ведомости, строительство, переустройство, оформление, ЭН, КДО, РЧ, СП, ВС и др.).
- Поддержка пользовательских правил через `custom_rules.json` и режим `--add`.
- Обход длинных путей Windows (>260 символов) через `\\?\` и `MoveFileW`.
- Автоматическое усечение итогового имени до 80 символов.
- Логирование в `rename_log.txt` с резервными файлами при блокировке.
- Обработка ошибок доступа с 3 повторными попытками и пропуском проблемных файлов.
- Итоговый отчёт со списком ошибок и количеством успешных операций.

### Известные ограничения
- Полноценная поддержка длинных путей — только на Windows.
- Пользовательские правила — простые подстроки (без регулярных выражений).
