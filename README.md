# File Name Shortener · Сокращение имён файлов и папок

[![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)]()
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

**File Name Shortener** — это кроссплатформенный (но оптимизированный под Windows) скрипт на Python для **автоматического сокращения длинных имён файлов и папок** по настраиваемым правилам.

Программа:

- Применяет словарь регулярных замен (например, `Раздел №5` → `Р5`, `Ведомость` → `В`, `Строительство` → `стр-во`).
- Заменяет все точки и пробелы на `_` (кроме расширения файла).
- Обрезает итоговое имя до **80 символов** для совместимости с любыми ФС.
- Поддерживает **длинные пути Windows** (> 260 символов) и **сетевые папки** (UNC).
- Работает в 4 режимах: добавление правил, предпросмотр, интерактивный и автоматический.
- Ведёт подробный лог и не прерывается при ошибках доступа — пропускает проблемные файлы и продолжает.
- Позволяет добавлять **пользовательские сокращения** без изменения кода (`custom_rules.json`).

## Быстрый старт

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/cherneyivan-cloud/file-name-shortener.git
cd file-name-shortener

# 2. Запустите скрипт (Python 3.8+)
python shorten_filenames.py
```

Появится интерактивное меню:

```
============================================================
  ПРОГРАММА АВТОМАТИЧЕСКОГО СОКРАЩЕНИЯ ИМЁН ФАЙЛОВ И ПАПОК
============================================================
Выберите режим работы:
  1. Добавить новые сокращения (пользовательские правила)
  2. Предварительный просмотр (только показать изменения)
  3. Интерактивный режим (показать изменения и запросить подтверждение)
  4. Автоматическая обработка (применить все изменения без запросов)
  0. Выход
============================================================
```

**Запуск с параметрами командной строки** (для автоматизации):

```bash
python shorten_filenames.py "C:\Мои документы\Проект" --dry-run   # предпросмотр
python shorten_filenames.py "C:\Мои документы\Проект" --apply     # применить
python shorten_filenames.py --add                                  # добавить правила
```

## Режимы работы

| Режим | Ключ CLI | Описание |
|-------|----------|----------|
| **Добавление правил** | `--add` | Интерактивно добавляет пользовательские сокращения в `custom_rules.json`. |
| **Предпросмотр** | `--dry-run` / `-n` | Показывает список изменений, **не переименовывая**. |
| **Интерактивный** | *(по умолчанию)* | Показывает изменения и запрашивает подтверждение `y/n`. |
| **Автоматический** | `--apply` / `-a` | Применяет все изменения без запросов, длинные имена усекаются автоматически. |

> ⚠️ **Рекомендация:** всегда делайте **резервную копию** папки перед первым запуском в автоматическом режиме.

## Встроенные правила

Полный список — в [`docs/RULES.md`](docs/RULES.md).

Краткая выборка:

| Исходное | Сокращение |
|----------|-----------|
| `Раздел №5` | `Р5` |
| `Подраздел №3` | `П3` |
| `Ведомость` / `Ведомости` | `В` |
| `Строительство` | `стр-во` |
| `Строительства` | `стр-ва` |
| `Переустройство` | `пер-во` |
| `Оформление` / `оформление` | `оф` |
| `Электроснабжение` | `ЭН` |
| `Конструкция_дор_одежды` | `КДО` |
| `Разбивочный_чертёж` | `РЧ` |
| `Сводный план` / `Сводный_план` | `СП` |
| `Внешние_ссылки` | `ВС` |
| `(изм.1)` / `Изм.2` | `И1` / `И2` |

Все замены выполняются **без учёта регистра**. После применения правил:

- Пробелы → `_`
- Все точки (кроме расширения) → `_`
- Множественные `_`/`-` схлопываются
- Итоговое имя обрезается до **80 символов**

## Пользовательские правила

Создайте файл `custom_rules.json` в каталоге со скриптом (или используйте режим `--add`):

```json
[
  { "original": "Рабочая документация", "replacement": "РД" },
  { "original": "Технический отчёт",    "replacement": "ТО" }
]
```

Правила применяются **до** встроенных, регистронезависимы, ищут **простую подстроку** (без регулярных выражений).

## Обработка длинных путей

Скрипт использует префикс `\\?\` (и `\\?\UNC\` для сети) и функцию `MoveFileW` из `kernel32.dll`, что позволяет:

- Обходить **все** файлы, даже если полный путь превышает 260 символов.
- Переименовывать их без ошибок `[WinError 206] (filename or extension is too long)`.
- Работать с UNC-путями (`\\server\share\...`).

Если файл занят другим процессом (`WinError 5`, `WinError 32`), скрипт делает **3 попытки с задержкой 1 с**, затем пропускает файл и продолжает работу.

## Логирование

Все действия записываются в `rename_log.txt` (в каталоге запуска):

```
=== Запуск 2026-10-19 14:30:00 ===
Корневая папка: C:\Проект
Найдено элементов: 152
Будет переименовано 148 элементов:
  Раздел 5\Ведомость.docx  ->  Р5\В.docx
  ...
УСПЕШНО: ...
ОШИБКА при ... -> ...: MoveFileW ошибка 5
---
СПИСОК ОШИБОК ---
```

**Если `rename_log.txt` заблокирован** (открыт в Блокноте/Excel), скрипт автоматически сохранит лог в `rename_log_1.txt`, `rename_log_2.txt` или `%TEMP%\rename_log.txt` — программа **не упадёт**.

## Требования

- **Python 3.8+**
- ОС: **Windows 7+** (используется WinAPI `MoveFileW`); на Linux/macOS скрипт работает в ограниченном режиме без длинных путей.
- Сторонние библиотеки — **не требуются** (только стандартная библиотека).

Файл `requirements.txt` оставлен пустым для совместимости с инструментами (`pip install -r requirements.txt` не упадёт).
